## 訓練神經網絡的流程-以預測罹患心血管疾病機率為例

<!--實驗目的
利用神經網路的迴歸模型來預測受測者於十年內可能發生動脈粥狀硬化心血管疾病（ASCVD）的機率。
設計原理
心臟血管疾病一直是世界上不少地區的主要死因之一，其中的動脈粥狀硬化心血管疾病（ASCVD, atherosclerotic cardiovascular disease）是因為體內膽固醇中脂肪累積，使得血管硬化、狹窄以及阻塞，由於早期症狀不明顯，所引發急性發病極為致命，然一旦發作，可能導致心絞痛、心肌梗塞甚至猝死。因此許多研究嘗試預測患者的 ASCVD 發病機率，以達到及早追蹤與治療。
目前來說，美國心臟病學會所推出的心血管疾病風險計算工具，能預測患者 10 年內發生 ASCVD 的機率，已被作為臨床上治療及使用藥物的依據。
雖然現在有不少網站在線上提供此風險計算工具，只要輸入相關資訊，如性別、年齡、血壓等就能計算發病機率。不過由於該公式為機密計算程式，且計算式不易取得，因此本實驗會試以既有資料集（來自資料科學平台 Kaggle），建立一個屬於我們自己的 ASCVD 風險計算模型。
